# CRM
This is a customer relations management software for an e-commerce company 

### Issue:
The company I was working for was using an open source ticketing system called, "open ticket". Unfortunately, it lacked to display some important information regading some products, such as; firmeware number, type, size, connection, and capacity. 

### Features:
- Data stored in local database
- Inventory management for hard drives
- Tab for entering RMA information and display
- Entry and display for UPC and labels

### Installation:
```bash
git clone https://github.com/adylon/CRM.git
cd CRM
python etickets.py
```
